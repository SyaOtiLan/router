# 主流供应商与客户端兼容矩阵

Router 的兼容边界按协议和端点定义，不按客户端品牌重复实现适配器。供应商只要实现下列协议之一，即可复用对应适配器；具体模型是否可用由 `provider_models` 的端点和能力元数据决定。

| 客户端/生态 | 协议入口 | 关键端点 | 供应商接入方式 | 用量结算 |
|---|---|---|---|---|
| OpenAI SDK、curl、LangChain、LlamaIndex、LiteLLM、Cursor、Cline、Continue、Dify、n8n | OpenAI Chat Completions | `/v1/chat/completions` | 原生 OpenAI 或 OpenAI-compatible | 上游 usage 优先 |
| OpenAI Responses SDK | OpenAI Responses | `/v1/responses` | 原生 Responses 或协议转换 | 上游 usage 优先 |
| Anthropic SDK、Claude Code | Anthropic Messages | `/v1/messages` | Anthropic 原生 | 上游 usage 优先 |
| Google GenAI、Vertex SDK | Gemini/Vertex | Gemini generateContent、Vertex Anthropic/GenAI | Gemini 原生、Vertex 或兼容协议 | 上游 usage 优先 |
| OpenAI embeddings 客户端 | Embeddings | `/v1/embeddings` | OpenAI-compatible、原生供应商 | 上游 usage 或模型计费规则 |
| 图像客户端 | Images | `/v1/images/*` | OpenAI-compatible 或供应商专用适配器 | 图片计费规则 |
| 音频客户端 | Audio | `/v1/audio/*` | OpenAI-compatible 或供应商专用适配器 | 音频计费规则 |
| 视频客户端 | Videos | `/v1/videos` | 供应商专用适配器 | 任务/时长计费规则 |
| Realtime 客户端 | Realtime WebSocket | `/v1/realtime` | OpenAI Realtime 或供应商专用适配器 | 连接/音频 usage |

## 供应商分层

- **原生协议供应商**：OpenAI、Anthropic、Google、Vertex、Azure、AWS Claude 等，使用专用适配器处理认证、请求和 usage。
- **OpenAI-compatible 供应商**：DeepSeek、Qwen、Mistral、Groq、xAI、Moonshot、Together、SiliconFlow、Novita、Ollama 及其他兼容服务，复用 OpenAI 适配器，仅配置 base URL、认证方式和模型目录。
- **专用端点供应商**：百度、腾讯、智谱、火山、MiniMax、Replicate 等，按端点注册专用适配器；模型目录声明支持的端点和参数。

## 发布与验证要求

每个发布模型必须具备：模型 ID、供应商、支持端点、输入/输出模态、支持参数、上下文/输出限制（如供应商可提供）、价格组件和 usage 可用性。管理端的模型测试应至少覆盖非流式、流式、工具调用和多模态请求中该模型声明支持的组合。

本矩阵不承诺供应商永久支持某个模型名称。目录同步或健康测试发现模型下线时，应将模型标记为 deprecated，而不是删除历史结算记录。
